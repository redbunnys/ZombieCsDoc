**生化模式 Ⅱ** 在经典感染的基础上引入了**进化系统**，尸潮会越战越强。

## 新增机制

### 僵尸进化

僵尸通过感染人类累积进化值，可多次变异升级：

- **生命值提升**：每次进化获得更高血量上限
- **技能解锁**：进化后获得特殊技能（如高速突进、远程投掷等）
- **形态变化**：外观随进化阶段改变，压迫感拉满

### 空投补给箱

回合进行中，地图上会随机投放**补给箱**，人类拾取后可获得：

- 强化武器（榴弹枪、双持冲锋枪等）
- 弹药补给与防化服
- 一次性特殊道具

## 策略要点

- 人类：前期抱团守点，中期争夺补给，用强化武器压制进化体
- 僵尸：尽早扩散感染，用数量滚起进化的雪球

## 配置项

```jsonc
// addons/swiftlys2/configs/plugins/ZombieCs/config.jsonc
{
  "mode2": {
    "enabled": true,
    "maxEvolutionStage": 3,      // 僵尸最大进化阶段
    "evolutionExpPerInfect": 25,
    "supplyDropInterval": 45,    // 空投间隔（秒）
    "supplyWeapons": ["weapon_m249", "weapon_xm1014", "weapon_negev"]
  }
}
```

:::note[进化阶段]
进化阶段越高，僵尸的生命值与抗击退能力越强，第三阶段会解锁专属技能。可在配置中调整各阶段的数值曲线。
:::
