**生化模式 Ⅰ** 是一切的起点，最纯粹的僵尸感染玩法。

## 规则

- 回合开始后，随机数名玩家觉醒为**母体僵尸**
- 人类被僵尸击杀后立即**转化为僵尸**并加入尸群
- 回合结束时仍有幸存人类，则人类获胜；全员感染则僵尸获胜

## 核心机制

### 母体觉醒

母体僵尸拥有更高的生命值与移动速度，是尸群扩散的源头。

### 击退与爆头

枪械命中僵尸会产生**击退效果**，爆头可造成额外伤害。合理利用地形与火力压制是守点的关键。

### 经典守点

弹药有限、退路有限。选择易守难攻的点位，与队友形成交叉火力，才能撑到回合结束。

## 相关指令

| 指令 | 说明 | 权限 |
| ---- | ---- | ---- |
| `!zm mode 1` | 切换至本模式 | 管理员 |
| `!zm start` | 立即开始一回合 | 管理员 |
| `!zm status` | 查看回合与感染者数量 | 所有人 |

## 配置项

```jsonc
// addons/swiftlys2/configs/plugins/ZombieCs/config.jsonc
{
  "mode1": {
    "enabled": true,
    "motherZombieRatio": 0.1,   // 母体数量占在线人数比例
    "roundTime": 180,           // 回合时长（秒）
    "knockbackMultiplier": 1.0, // 击退倍率
    "headshotMultiplier": 3.0   // 爆头伤害倍率
  }
}
```

:::caution[注意]
修改配置后需执行 `!zm reload` 使其生效，正在进行的回合不受影响。
:::
