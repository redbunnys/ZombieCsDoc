**生化模式 Z** 是玩法深度最高的模式：等级成长 + 随机能力池，让每一局的体验都独一无二。

## 核心机制

### 局内等级

人类与僵尸在对局中通过击杀、感染、造成伤害等方式获取经验，提升局内等级。

### 随机变异能力

每次升级可从随机刷新的能力中进行选择，能力池包含数十种效果：

- **跳跃强化**：超级跳跃，轻松破点
- **神速**：移动速度大幅提升
- **钢铁之躯**：减免枪械伤害
- **弹药狂热**：无限弹药
- ……更多能力持续加入

### 自由组合

能力之间可以叠加组合，打造出只属于你的终极 build——无论是刀枪不入的钢铁尸王，还是火力全开的移动炮台。

:::note
能力的刷新具有一定随机性，根据当前局势灵活选择才是上策。
:::

## 操作方式

| 操作 | 说明 |
| ---- | ---- |
| `!zm menu` | 打开个人能力面板，查看当前已获得的能力 |
| 升级时按提示 | 从随机刷新的 3 个能力中选择一个 |
| 聊天框输入能力编号 | 快速选取 |

## 配置项

模式 Z 的能力池与成长曲线可在配置文件中调整：

```jsonc
// addons/swiftlys2/configs/plugins/ZombieCs/config.jsonc
{
  "modeZ": {
    "enabled": true,
    "maxLevel": 30,
    "choicesPerLevelUp": 3,
    "abilityPool": ["superjump", "speed", "steelbody", "infiniteammo"],
    "humanExpPerKill": 20,
    "zombieExpPerInfect": 30
  }
}
```

:::tip[扩展能力池]
能力以模块化方式实现，新增能力只需追加到 `abilityPool` 并在 `resources/` 中提供对应参数，无需改动插件本体。
:::
