**ZombieCs** 是一款运行于 Counter-Strike 2 社区服务器的游戏插件，基于 [SwiftlyS2](https://swiftlys2.net/) 框架以 C# 开发，致力于在 Source 2 引擎上完整复刻世纪天成 CSOL 的经典生化玩法——包括**生化模式 1、生化模式 2、生化模式 3、生化模式 Z** 以及**生化盟战**。

想回到宣传页？访问 [首页](/zombiecs) 查看五大模式的完整介绍。
:::

## 技术栈

| 项目 | 说明 |
| ---- | ---- |
| 运行框架 | SwiftlyS2（C++ 核心 + C# 托管层） |
| 开发语言 | C# / .NET |
| 目标游戏 | Counter-Strike 2 社区服务器 |
| 支持平台 | Windows / Linux |
| 开源协议 | 插件本体遵循 GPLv3 友好许可，与 SwiftlyS2 生态一致 |

## 玩法总览

| 模式 | 核心机制 |
| ---- | -------- |
| 生化模式 Ⅰ | 母体随机觉醒，击杀即感染，经典守点 |
| 生化模式 Ⅱ | 僵尸多阶段进化，人类空投补给 |
| 生化模式 Ⅲ | 英雄觉醒系统，僵尸怒气爆发 |
| 生化模式 Z | 局内等级成长 + 随机变异能力组合 |
| 生化盟战 | 人类 vs 尸潮双阵营大规模团战 |

## 为什么选择 SwiftlyS2

- **现代 C# 开发**：async/await、依赖注入、完整的 .NET 生态
- **原生引擎接入**：直接调用 Source 2 内部接口，几乎无性能损耗
- **热重载**：替换插件即可生效，状态可跨重载保留
- **内存安全**：托管抽象层避免了原生插件常见的内存泄漏与崩溃
- **完整 API**：命令、CVar、实体、事件钩子、Protobuf 网络消息、数据库、菜单、音效一应俱全

## 插件特性

- **CS2 原生体验**：低延迟、高帧率，画质全面进化
- **五大经典玩法**：CSOL 老玩家的青春一次集齐
- **持续更新**：地图、武器、僵尸模型与平衡性持续迭代
- **公平竞技**：无数值付费，强度靠枪法与策略
